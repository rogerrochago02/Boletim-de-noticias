# Boletim de Notícias

Página web com conteúdo sobre autocuidado e qualidade de vida para a juventude.

**Demo:** https://rogerrochago02.github.io/Boletim-de-noticias/

## Tecnologias

- HTML5
- CSS3

## Estrutura

- `index.html` — estrutura e conteúdo da página
- `style.css` — estilos e layout

## Como executar

```bash
git clone https://github.com/rogerrochago02/Boletim-de-noticias.git
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
